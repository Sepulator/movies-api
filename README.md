## Getting Started

### Steps

#### 1. Clone [repository](https://github.com/Sepulator/movies-api.git)

```bash copy
  git clone https://github.com/Sepulator/movies-api.git
```

#### 2. Switch to `api-queries` branch

```bash copy
  git switch api-queries
```

#### 3. Open project directory and install dependencies

```bash copy
  npm install
```

#### 4. Start the development server

```bash copy
  npm run dev
```

This command starts the dev server locally `http://localhost:5173/`.
